## 原生 IP、住宅 IP、双 ISP，到底差在哪

三者不是同一件事，价格差一倍多半就差在这里。

**原生 IP** 指 IP 注册地和服务器所在地一致，没经过转发。这是最基础的要求，但门槛最低。

**住宅 IP** 指 IP 归属的是当地家庭宽带运营商，不是机房托管商。IP 数据库（Scamalytics、ipinfo 这类）会把它标成"住宅用户"，平台扫描时看到的画像就接近真实用户。

**双 ISP** 指这个 IP 同时挂在两家当地运营商的认证属性下，检测工具里的"住宅"特征更稳定，也更贵。

信任度从高到低排：双 ISP 住宅原生 > 单 ISP 住宅 > 普通原生 > 数据中心 IP。

有个容易被忽略的细节：标着"原生 IP"不等于就是住宅 IP。有的服务商卖英国线路，IP 归属地确实是英国，但 ASN 属于普通 IDC 段，在 TikTok 眼里仍是机房。WePC 官网自己就把这类产品单独标了出来——英国 TikTok 专线 AU$10.90 那一档，配置表里明写"**非家宽 ip**"。它比家宽版便宜 4 澳元，省下的就是这层身份。

真正的家宽机型，官网会写"原生家宽 IPv4"或"家宽双 ISP IP"。买了之后建议上 ipinfo 或 ping0 查一遍 ASN 和用途标记，五分钟的事，比事后怀疑账号被限流划算。

## 直播的流量账：1.5TB 双向能播多少场

很多人看到"200Mbps 带宽、1.5TB 流量"就觉得绰绰有余，播半个月收到限速通知才发现不对。

先算清楚"双向"的意思：上行推流和下行拉流、传文件、看后台，全部计入同一个 1.5TB 额度。直播是持续上行，这是消耗最大的一项。

按常见参数估算：1080P 推流码率取 5Mbps，一场播 4 小时，上行数据量约 5Mbps × 14400 秒 ÷ 8 ≈ 9GB。一个月播 30 场，大约 270GB。看起来离 1.5TB 还很远。

但实际消耗远不止推流这一项。直播同时会有下行（看弹幕、看评论区、监看画面回传），多开一个监看窗口、后台同步素材、上传剪辑好的视频，这些都在同一个池子里扣。做多账号的话，素材上传和备份的消耗可能比推流本身还大。

所以按 1.5TB 规划时，留一半余量比较稳——把它当成 750GB 可用上行来估。真要做每天 8 小时不间断直播，1.5TB 会紧张，这时该看的是不限流量或者更大流量的方案，而不是继续加带宽。

另外注意韩国、马来等套餐标的"超流量限速 5Mbps"：限速不是断网，但 5Mbps 对 1080P 推流刚好卡在临界线上，画质会掉。
